# Leaf & Latte — Taking Order Cafe

Aplikasi pemesanan cafe berbasis web dengan tema **Leaf & Latte** (soft pink + warm chestnut).

## Tech Stack
- PHP 8.0+ (mysqli, prepared statement)
- MariaDB / MySQL 5.7+
- Tailwind CSS v3 (CDN)
- Phosphor Icons (CDN, free MIT)

## Persyaratan
- PHP >= 8.0
- Ekstensi: `mysqli`, `fileinfo`
- Web server Apache / Nginx

## Instalasi
1. Copy folder ke `htdocs/`.
2. Import `db_cafe.sql` via phpMyAdmin.
3. Sesuaikan kredensial di `config/koneksi.php`.
4. Buat folder `uploads/menu/` (writable).
5. Buka `http://localhost/nama-folder/`.

## Akun Default
- Admin: `admin` / `admin123`
